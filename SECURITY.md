# Reporting a security issue

Please report a vulnerability privately to **security@cotterpin.io**, not in a public issue.

How we handle reports, what to include and what you can expect from us:
<https://cotterpin.io/legal/security-disclosure.html>.

How Cotterpin itself is secured (approvals, hardened mode, what runs where):
[docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md).
