# Refusal catalogue

Every refusal Cotterpin raises has a code. `cotterpin explain <code>` prints the same cause, fix and command as this page; every command-line refusal prints them too.

This page is generated from the catalogue (`cotterpin/kernel/refusal_entries.py` and each pack's `refusals.py`). Do not edit it by hand; regenerate it with:

```sh
cotterpin explain --markdown > docs/product/REFUSALS.md
```

Words in angle brackets, such as `<run-id>`, are your own values.
